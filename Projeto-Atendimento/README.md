# Sistema de Atendimento em C++

Programa que simula um sistema de atendimento por senhas.

Opções:
0 - Sair
1 - Gerar senha
2 - Realizar atendimento

Funcionalidades:
- Gera senhas sequenciais
- Armazena as senhas geradas em uma fila
- Realiza atendimentos na ordem de chegada
- Mantém registro das senhas atendidas
- Exibe a quantidade de senhas aguardando atendimento
- Só permite encerrar o programa quando não houver senhas pendentes

Implementação utilizando filas em vetor e em lista encadeada (ponteiros).
