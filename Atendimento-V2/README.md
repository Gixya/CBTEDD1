# Sistema de Atendimento V2

Programa em C++ que simula um sistema de atendimento por senhas utilizando filas e listas encadeadas.

Menu:
0 - Sair
1 - Gerar senha
2 - Abrir guichê
3 - Realizar atendimento
4 - Listar senhas atendidas

Funcionalidades:
- Geração de senhas sequenciais.
- Controle de fila de espera.
- Cadastro de guichês.
- Registro das senhas atendidas por cada guichê.
- Consulta das senhas atendidas por um guichê específico.
- Exibição da quantidade de senhas aguardando atendimento e do número de guichês abertos.
- Encerramento permitido apenas quando não houver senhas pendentes.

Implementação realizada utilizando ponteiros e listas encadeadas.
